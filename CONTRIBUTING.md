# Contributing

Contributions are welcome for the Russian translation layer of this repository:

- corrections to Russian translations;
- corrections to reference assessments;
- improvements to the static site generator;
- documentation improvements for Russian-speaking users.

Please keep changes small and source-backed. For translation fixes, preserve the
paragraph structure of the English SPDX text and do not soften legal modality.

For issues in the upstream SPDX License List itself, such as adding a new license
or correcting the canonical English text, use the official upstream channels:

- SPDX License List Data: <https://github.com/spdx/license-list-data>
- SPDX license-list-XML contribution guidance:
  <https://github.com/spdx/license-list-XML/blob/master/CONTRIBUTING.md>
- SPDX LicenseListPublisher:
  <https://github.com/spdx/LicenseListPublisher>

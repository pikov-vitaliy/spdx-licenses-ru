Исключение GPL компании Qt 1.0

Исключение 1:

В качестве особого исключения вы можете создать большее произведение, которое содержит вывод этого приложения, и распространять это произведение на условиях по вашему выбору, при условии, что произведение не произведено иным образом из этого приложения и не основано на нём и при условии, что произведение само по себе не генерирует вывод, который содержит вывод этого приложения в его первоначальной или изменённой форме.

Исключение 2:

В качестве особого исключения вы имеете разрешение объединять это приложение с Плагинами, лицензированными на условиях по вашему выбору, для создания исполняемого файла, и копировать и распространять полученный исполняемый файл на условиях по вашему выбору. Однако исполняемый файл должен сопровождаться заметным уведомлением, предлагающим всем пользователям исполняемого файла весь исходный код этого приложения, исключая исходный код независимых модулей, но включая любые изменения, которые вы внесли в это приложение, на условиях настоящей лицензии.

# SPDX Licenses RU

Русско-английский статический справочник лицензий из официального
**SPDX License List 3.28.0**.

Проект добавляет к отдельным SPDX-страницам:

1. неофициальный русский перевод текста лицензии или исключения;
2. краткую справочную оценку условий: разрешения, требования, ограничения и
   предварительный вердикт;
3. удобную отметку готовых страниц в индексах сайта.

Английский оригинал SPDX сохраняется на странице без изменений и остается
приоритетным текстом. Русский перевод и оценка предназначены для ориентира и не
являются юридической консультацией.

## Зачем

Многие разработчики, инженеры по безопасности и специалисты по лицензированию
быстро сталкиваются с SPDX, но не всегда хотят начинать с длинного английского
юридического текста. Этот справочник помогает быстрее понять смысл лицензии,
основные обязанности и заметные риски, сохраняя рядом официальный оригинал.

Проект развивается постепенно: сейчас переведена только часть SPDX License List,
дальше покрытие можно расширять лицензия за лицензией.

## Как пользоваться

Готовый сайт находится в `website/`. Его можно открыть локально или развернуть на
любом статическом хостинге.

```powershell
cd website
py -m http.server 8765
```

После запуска локальный предпросмотр будет доступен по адресу
`http://127.0.0.1:8765/`.

Готовые переводы помечены `✅` в `website/index.html` и
`website/exceptions-index.html`.

## Структура

- `website/` — готовый статический сайт.
- `rbpo/generate.py` — генератор русских блоков.
- `rbpo/verdicts.json` — метаданные оценок и статусы переводов.
- `rbpo/translations/` — русские переводы.
- `rbpo/pristine/` — неизмененные HTML-снимки исходных SPDX-страниц.
- `json/`, `text/`, `html/`, `rdfa/`, `rdfnt/`, `rdfturtle/`, `rdfxml/`,
  `SPDXv3/`, `license-list-XML/` — исходные данные SPDX в разных форматах.
- `README.upstream.md` — оригинальное описание upstream-набора данных SPDX.

## Генерация

```powershell
py rbpo\generate.py
```

Команда пересобирает все страницы, перечисленные в `rbpo/verdicts.json`.
Генератор публикует русский блок только для записей со статусом
`translation_status: "verified"` и успешной проверкой количества абзацев.

## Статус покрытия

В текущей версии опубликовано 75 страниц: 67 лицензий и 8 исключений `WITH`.
Полное покрытие SPDX License List остается целью дальнейшего развития.

Публичная версия сайта: <https://spdx.pikov.expert/>.

## Источник данных и лицензия

Репозиторий основан на
[SPDX License List Data](https://github.com/spdx/license-list-data) версии 3.28.0
(SPDX Workgroup, a Linux Foundation Project).

Данные SPDX распространяются на условиях
[Creative Commons Attribution 3.0](https://creativecommons.org/licenses/by/3.0/).
Русские переводы и справочные оценки в этом репозитории публикуются на тех же
условиях, если явно не указано иное.

Тексты самих лицензий принадлежат их авторам и приведены как часть справочного
набора SPDX.
